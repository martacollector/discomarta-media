# Discomarta — Media Archive

Хранилище изображений для личного онлайн-каталога коллекции виниловых пластинок (LP), компакт-дисков (CD) и аудиокассет (MC).

## Структура папок
* `artists/<artist-id>/collection.jpg` — общее фото подборки исполнителя
* `artists/<artist-id>/<release-id>/` — фотографии конкретного издания
